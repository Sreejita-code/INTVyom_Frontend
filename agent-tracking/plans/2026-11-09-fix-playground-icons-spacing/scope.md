# Scope — playground icons and spacing

## Request

Review STT, LLM, and TTS because icons are missing and the top/bottom spacing is not polished,
especially after Optional configuration is expanded.

## In scope

- Add restrained icons to the form section headings on all three standalone playgrounds.
- Preserve the existing page-title, Result, and Optional configuration icons.
- Restore visible bottom page padding when the final Optional configuration card is expanded.
- Verify collapsed and expanded states at the five supported viewport widths.

## Out of scope

- API behavior, form data, requests, response rendering, navigation, or a broader visual redesign.
- Decorative icons on every field or button.
